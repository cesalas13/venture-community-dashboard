# Operator VC Check

Role: busy venture community operator, not technical, first-time dashboard user.

Use Operator to answer three questions:
- What is confusing?
- What feels risky to click?
- What should the next action say instead?

Return format:
- Unclear label or section
- Why it matters
- Cleaner wording or placement

Check only:
- First click on the Home page
- Human in the loop approval step
- Real vs sandbox safety
- Inputs and links that open outside the dashboard
- Jargon near primary actions

Skip:
- Code suggestions
- Strategy decisions
- Long explanations
- Live approvals or sends
